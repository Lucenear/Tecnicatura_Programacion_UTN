# Food Store Frontend

Frontend desarrollado con React, TypeScript, Vite, Tailwind CSS, TanStack Query, TanStack Form y TanStack Table (v8).

## Requisitos

- Node.js 18 o superior
- pnpm (o npm)

## Instalacion

```bash
pnpm install
```

## Ejecucion en desarrollo

```bash
pnpm dev
```

La aplicacion estara disponible en:
http://localhost:5173

## Compilacion de produccion

```bash
pnpm build
```
