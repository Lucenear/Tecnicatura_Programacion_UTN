# Food Store Frontend

Interfaz de administracion de productos para Food Store desarrollada con React, TypeScript, Vite y Tailwind CSS.

## Requisitos

- Node.js 18 o superior
- npm 9 o superior

## Instalacion

Instalar las dependencias del proyecto:

```bash
npm install
```

## Ejecucion

Iniciar la aplicacion en modo desarrollo:

```bash
npm run dev
```

La aplicacion estara disponible en el navegador en:

```
http://localhost:5173
```

## Compilacion

Para generar los archivos de produccion:

```bash
npm run build
```
