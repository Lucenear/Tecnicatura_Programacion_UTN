# Frontend Catalogo de Categorias

Aplicacion web desarrollada con React, TypeScript, Vite y Tailwind CSS para la administracion de categorias mediante consumo de API REST.

El diseño de la interfaz fue realizado con Tailwind CSS. Permite añadir, editar y eliminar categorias en tiempo real.

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- TanStack Query
- React Router
- Tailwind CSS

## Instalacion y ejecucion

1. Instalar dependencias:

pnpm install

2. Iniciar servidor de desarrollo:

pnpm dev

El servidor se ejecutara en:
http://localhost:5173

3. Compilar para produccion y verificacion de tipos:

pnpm build
