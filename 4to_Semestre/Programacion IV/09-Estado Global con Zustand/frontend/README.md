# Food Store Frontend

Frontend desarrollado con React, TypeScript, Vite, Tailwind CSS, TanStack Query, TanStack Form, TanStack Table y Zustand.

## Requisitos

- Node.js 18 o superior
- pnpm (o npm)

## Instalacion

```bash
pnpm install
```

Configurar variables de entorno:

```bash
cp .env.example .env
```

## Ejecucion en desarrollo

```bash
pnpm dev
```

La aplicacion estara disponible en:
http://localhost:5173
