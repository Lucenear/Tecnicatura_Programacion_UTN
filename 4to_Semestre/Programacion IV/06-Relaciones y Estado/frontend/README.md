# Frontend React - CRUD de Categorias

Aplicacion frontend construida con React, TypeScript, Vite y Tailwind CSS para la gestion de categorias mediante consumo de API REST con fetch nativo.

## Requisitos

- Node.js v18 o superior
- pnpm (o npm)

## Instalacion

pnpm install

## Ejecucion

Para iniciar el servidor de desarrollo:
pnpm dev

La aplicacion se ejecutara en http://localhost:5173

## Verificacion de tipos

Para verificar tipos de TypeScript y compilar:
pnpm build
